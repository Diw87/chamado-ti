# CHAMADO T.I.

Sistema web para gerenciamento de chamados do Setor de Tecnologia da Informação da Prefeitura Municipal de Olho d'Água das Cunhãs.

## Recursos da versão 1.0

- Painel com indicadores
- Abertura de chamados
- Numeração automática
- Secretaria/setor solicitante
- Categoria e prioridade
- Status: Aberto, Em atendimento, Aguardando e Resolvido
- Técnico responsável
- Pesquisa e filtros
- Histórico de atividades
- Relatórios por setor e categoria
- Exportação CSV
- Layout responsivo para computador e celular

## Armazenamento

Nesta primeira versão, os dados ficam armazenados no navegador através de `localStorage`. Isso é ideal para demonstração e validação da interface.

Para uso real e simultâneo em várias secretarias, a próxima versão deve utilizar autenticação e banco de dados centralizado.

## GitHub Pages

O site é estático e pode ser publicado diretamente pelo GitHub Pages usando a branch `main` e a pasta `/ (root)`.
